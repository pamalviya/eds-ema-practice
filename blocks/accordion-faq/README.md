# accordion-faq

Custom **accordion** block. Purpose: Frequently asked questions list with expand/collapse answers.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: question text (include numbering if desired, e.g. "1. ..."); cell 2: answer rich text. When there are more than 6 items, the rest are hidden behind a "see more" button.

## Supported variations

No variations.
