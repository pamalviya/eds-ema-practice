# carousel-hero-banner

Custom **carousel** block. Purpose: Full-width rotating promo banner at the top of the page.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: banner image (message text is baked into the art, keep alt text); cell 2 (optional): CTA link or label. Dots and 5s autoplay (paused on hover/focus and for reduced motion) are added by the block.

## Supported variations

No variations.
