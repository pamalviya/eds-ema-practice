# carousel-logo-marquee

Custom **carousel** block. Purpose: Continuously auto-scrolling row of partner logos with no controls.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one cell per row: partner logo image with alt text = partner name (optionally linked). The list is duplicated by the block for a seamless loop; pauses on hover/focus and stops for reduced motion.

No variations.
