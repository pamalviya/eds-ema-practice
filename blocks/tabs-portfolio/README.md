# tabs-portfolio

Custom **tabs** block. Purpose: Tabbed product/portfolio showcase where each tab holds an inner image-left/text-right slider.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: tab label; cell 2: one or more slides in order, each = image, then heading (h3), paragraph, CTA link. Each image starts a new slide; 2+ slides in a panel get prev/next arrows (desktop) and dots, and can be swiped on touch devices. On mobile the tab bar scrolls horizontally with prev/next tab chevrons. Images hosted on other origins are used as-is (only same-origin images go through the EDS image pipeline).
