# cards-article

Custom **cards** block. Purpose: Grid of article teaser cards (case studies, blog posts).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: image; cell 2: title paragraph linked to the article, description paragraph, optional date paragraph (e.g. "October 21, 2026"). The whole card is clickable via the title link and gets a decorative arrow (footer row: optional date with calendar icon on the left, arrow on the right).

Layout: 3 columns (max 323px each, 35px gap) from 900px, 2 columns from 600px; below 600px the cards become a horizontal scroll-snap slider, one card per view, with clickable dots that follow the scroll position.

No variations.
