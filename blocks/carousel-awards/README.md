# carousel-awards

Custom **carousel** block. Purpose: Horizontally scrolling row of award cards with prev/next arrows.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: award logo image; cell 2: bold title paragraph followed by a description paragraph. Shows 1/2/3 cards at mobile/tablet/desktop.
