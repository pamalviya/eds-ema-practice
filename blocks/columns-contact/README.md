# columns-contact

Custom **columns** block. Purpose: Side-by-side contact methods (icon, label, value).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row with one cell per contact method; each cell: icon image, label paragraph, bold value paragraph. Bare phone numbers become tel: links and email addresses become mailto: links.

## Supported variations

No variations.
